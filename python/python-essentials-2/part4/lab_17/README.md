# [Lab 17] - Sorted Character Frequency Histogram (File Output)

## 📝 User Story

**As a** Python student / developer,
**I want to** improve the character frequency program so that it sorts the results by frequency (highest to lowest) and saves the output into a new file,
**So that** I can easily identify the most common characters and maintain a saved record of the cryptographic analysis.

---

## ✅ Acceptance Criteria

**Scenario: Sorting by frequency and saving to a file**
* **Given** a valid input text file (e.g., `samplefile.txt`) containing the text "cBabAa"
* **When** the user runs the program and inputs the filename
* **Then** the program should sort the histogram based on character frequency (largest counter first) and create a new file named `samplefile.txt.hist` containing the following exact output:

    a -> 3
    b -> 2
    c -> 1

**Scenario: Using a lambda function for sorting**
* **Given** the dictionary containing the character counts
* **When** the program prepares to format the output
* **Then** it must successfully use a lambda function to change the sorting order from alphabetical (by key) to frequency-based (by value, in descending order).

**Scenario: Edge Case/Error Handling (Write Permissions / File Not Found)**
* **Given** a filename that does not exist or a directory where the user lacks write permissions
* **When** the program attempts to read the input or write the `.hist` file
* **Then** the program should handle standard I/O exceptions gracefully, displaying an appropriate error message to the user without crashing.

---

## 🛠️ Technical Notes

* **Implementation Details:** * You will need to open the output file using the `'w'` (write) mode. The output filename can be dynamically generated by appending `'.hist'` to the original filename string.
  * To sort the dictionary by its values (frequencies), use the built-in `sorted()` function on the dictionary's `.items()`. You should pass a lambda function to the `key` parameter (e.g., `key=lambda x: x[1]`) and set `reverse=True` to ensure descending order.
* **Complexity:** 
  * **Time:** O(N), where N is the number of characters read from the file. Sorting the dictionary takes O(K log K) where K is the number of unique letters (at most 26), making the sorting step effectively O(1).
  * **Space:** O(1), as the dictionary will hold a maximum of 26 key-value pairs regardless of the input file size.
* **Dependencies:** Only standard Python library functions and methods (File I/O).
