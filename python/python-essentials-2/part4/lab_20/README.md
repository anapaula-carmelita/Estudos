# [Lab 20] - Formatting Date and Time

## 📝 User Story

**As a** Python student / developer,
**I want to** create a specific `datetime` object and format it into several different string representations using the `strftime` method,
**So that** I can practice using various formatting directives and improve my skills in reading Python's official documentation to find the correct format codes.

---

## ✅ Acceptance Criteria

**Scenario: Date and Time Object Creation**
* **Given** the requirement to represent a specific moment in time
* **When** the program is executed
* **Then** it must successfully create a `datetime` object corresponding exactly to November 4, 2020, at 14:53:00.

**Scenario: Accurate Formatting Output**
* **Given** the created `datetime` object
* **When** the `strftime` method is called multiple times with different format strings
* **Then** the program should print the following exact results, line by line:
```
    2020/11/04 14:53:00
    20/November/04 14:53:00 PM
    Wed, 2020 Nov 04
    Wednesday, 2020 November 04
    Weekday: 3
    Day of the year: 309
    Week number of the year: 44
```
**Scenario: Directive Usage Enforcement**
* **Given** the code implementation for the output
* **When** reviewing the source code
* **Then** each printed result line must be generated by calling the `strftime` method on the datetime object, and the format argument must contain the appropriate directives (e.g., `%Y`, `%B`, `%j`).

---

## 🛠️ Technical Notes

* **Implementation Details:** * You will need to import the `datetime` module (specifically the `datetime` class).
  * Instantiate the date using `datetime(2020, 11, 4, 14, 53, 0)`.
  * You must consult the Python documentation for `strftime()` formatting codes to find the exact directives needed for each line (for example: `%Y` for a 4-digit year, `%B` for the full month name, `%p` for AM/PM, `%j` for the day of the year, and `%W` or `%U` for the week number).
* **Complexity:** 
  * **Time:** O(1), since formatting a single static date involves a constant number of straightforward operations.
  * **Space:** O(1), as only a single `datetime` object and a few strings are stored in memory.
* **Dependencies:** The standard Python `datetime` module.
