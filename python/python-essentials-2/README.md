## 📖 Sobre esta Pasta

Esta seção do meu repositório de estudos é dedicada exclusivamente às minhas resoluções para os laboratórios práticos do curso **Python Essentials 2**. 

O foco principal deste material é aprofundar os conhecimentos em módulos, pacotes, exceções, processamento de strings e programação orientada a objetos (POO), consolidando a minha preparação para o exame de certificação **PCAP (Python Certified Associate Programmer)**.

## 🚀 O que você vai encontrar aqui?

Os scripts estão organizados de acordo com os módulos do curso. Aqui estão alguns dos conceitos práticos aplicados:

- [x] 📦 **Módulos e Pacotes:** Criação, uso e organização.
- [x] ⚠️ **Exceções:** Tratamento de erros e construção de hierarquias de exceções personalizadas.
- [x] 🔤 **Strings:** Métodos avançados de processamento de texto.
- [x] 🧩 **Orientação a Objetos (POO):** Classes, métodos, herança e polimorfismo.
- [x] 📁 **Arquivos:** Manipulação de arquivos I/O.
