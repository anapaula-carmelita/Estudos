## 🎯 Project Vision and Motivation

As a Systems Analyst acting as a **Software Engineer**, I believe in treating study projects with the same rigor as production software. 

To reflect real-world development practices, this project bridges the gap between learning requirements and technical implementation. I am treating this curriculum as a software product release cycle. My methodology includes:

*   **User Story Mapping:** Visualizing the learning journey across all the intermediate modules.
*   **Agile Execution:** Managing tasks via GitHub Projects (Kanban) using releases and time-boxed Sprints.
*   **Requirements Analysis:** Documenting the logic, memory constraints, and needs for every C lab before coding.
*   **Engineering Focus:** Prioritizing deep technical understanding, robust memory management, and code quality over exam-cramming.

## 🗺️ Requirements & Agile Planning Overview

This project is structured using standard Agile taxonomy to break down the complexity of the course into deliverable increments.

### 1. The Epic: Intermediate C Mastery (CLA Track)
* **Goal:** Attain practical, deep mastery of intermediate C concepts by solving all proposed labs in the C Essentials 2 curriculum.
* **Scope:** The 3 core modules provided by the C++ Institute for the CLA intermediate level (Course CE2).

### 2. Releases (The Modules)
The Epic is divided into three major Releases (representing each module of the course). These act as the major milestones of my learning journey:
* **Release 1:** Functions and Structures.
* **Release 2:** Connecting to the Real World: Files and Streams.
* **Release 3:** Preprocessor, Declarations, and Storage Classes.

### 3. User Stories (The Labs)
Each Release is broken down into specific User Stories, which are the **practical laboratories**. 
* Each User Story (Lab) acts as a standalone requirement.
* Before coding, each story receives its own documentation detailing the **Business Logic**, **Memory Flow**, and **Acceptance Criteria**.

## 🚀 What you will find here

The scripts and documentation demonstrate analytical and low-level coding skills. Here are the practical concepts applied:

- [ ] 🧩 **Structures & Functions:** Managing complex data, recursive collections, and pointers as function parameters.
- [ ] 💾 **File & Stream Operations:** Stream manipulation, raw I/O, and error handling (`errno`).
- [ ] ⚙️ **The Preprocessor:** Parameterized macros, conditional compilation, and `#define` directives.
- [ ] 📦 **Storage Classes:** Understanding scope, lifetime, and complex declarations.
- [ ] 🛠️ **Build & Automations:** Creating Makefiles for compiling and testing C programs efficiently.
