## 📖 Sobre esta Pasta do Repositório

Esta seção do meu repositório de estudos é dedicada exclusivamente às minhas soluções para os laboratórios práticos e exercícios do curso da certificação **CLE (C Certified Entry-Level Programmer)**, chancelado pelo C++ Institute.

O objetivo principal deste material é revisar e solidificar minha base em estruturação de código, gerenciamento e alocação de memória (ponteiros), e manipulação de tipos de dados mais próximos ao hardware, enquanto consolido minha preparação para o teste final. 🚀

## 🎯 Visão do Projeto e Metodologia (Lean Agile)

Como o objetivo deste repositório é uma revisão cirúrgica e o aprofundamento técnico na linguagem C, optei por uma abordagem **Lean** (enxuta). Sem a sobrecarga de gestão de tarefas em um board Kanban, o foco total está na engenharia de software pura e na qualidade da entrega.

O fluxo de trabalho está estruturado nos seguintes pilares:
- 📖 **User Stories como Guia:** Os requisitos de cada laboratório são traduzidos em Histórias de Usuário claras e diretas, servindo como o único contrato necessário antes de codificar.
- 🧪 **Test-Driven e Validação:** Aplicação de testes unitários para validar a lógica das funções (utilizando recursos nativos como `<assert.h>`), garantindo que o código em C seja tão testável quanto em linguagens de alto nível.
- 📦 **Entregas Iterativas e Documentadas:** Subindo códigos aos poucos, evoluindo as implementações a cada commit e detalhando o uso de bibliotecas padrão (`stdio.h`, `stdlib.h`, `string.h`).
- ✅ **Code Quality & Memory Safety:** Atenção rigorosa à gestão manual de memória, com foco absoluto na ausência de vazamentos (uso correto do ciclo `malloc`/`free`) e na manipulação segura de ponteiros.
